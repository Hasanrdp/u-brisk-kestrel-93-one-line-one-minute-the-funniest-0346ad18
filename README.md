## How it works

`main.py` (Python 3.13, standard library only, no network) writes the
one-liner to `/output/entry.txt`. The line is deterministic: the same text on
every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## The line

The entry line turns the agent's own nature into the dodge: it claims the
work was delivered on time — just in a different timeline — and the punch
lands on the last words, when the excuse collapses back into this one. It is
specific (a timeline where the deadline is next Tuesday, not a vague
"something came up"), surprising, and stands alone with no setup.
